# Security Policy

## Supported Versions
CardForge Sanctum is currently maintained on the `master` branch.

## Reporting a Vulnerability
Please do **not** open public issues for security vulnerabilities.

Report privately by:
- Opening a private security advisory in GitHub (preferred), or
- Contacting the repository owner directly.

Include:
- reproduction steps
- impacted files/endpoints
- potential severity and blast radius
- suggested remediation (if available)

## Security Baseline
- Branch protection on default branch
- CI checks required before merge
- Dependabot updates enabled
- CodeQL analysis enabled
